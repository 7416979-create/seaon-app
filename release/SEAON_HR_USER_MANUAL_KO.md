## 2. 설치 방법

1. 휴대폰에서 위 링크를 눌러 APK 파일을 다운로드합니다. (보통 "다운로드" 폴더에 저장)
2. 다운로드 완료 알림 또는 "내 파일 → 다운로드"에서 APK 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켠 뒤 뒤로 가기를 누릅니다.
4. **설치**를 누릅니다.
5. Play 프로텍트가 "확인되지 않은 앱" 경고를 띄우면 **무시하고 설치**(또는 "세부정보 더보기 → 무시하고 설치")를 누릅니다.
   이 앱은 Play 스토어를 거치지 않고 직접 배포하는 앱이라 이 경고가 나옵니다.
6. 설치 후 홈 화면에 **"근태관리"** 아이콘이 생깁니다.

**요구 사항:** 안드로이드 5.0 이상

## 3. 사용 방법

### 첫 실행
1. **"근태관리"** 아이콘을 누르면 로고 화면이 2초간 나온 뒤 로그인 화면으로 이동합니다.
2. 이메일과 비밀번호를 입력하고 **로그인**을 누릅니다.

### 화면 구성 (하단 탭)
- **출퇴근**: 출근 / 퇴근 버튼. 누르면 위치 확인 → 회사 WiFi 확인 → 2단계 인증 창이 뜹니다.
  2단계 인증 창에 표시된 6자리 숫자를 입력칸에 그대로 입력하고 **확인**을 누릅니다.
- **기록**: 출퇴근 기록 목록
- **통계**: 근무 통계
- **설정** (오른쪽 위 톱니바퀴): 백그라운드 GPS 추적, 데이터 동기화, 앱 정보, 개인정보처리방침, 로그아웃

### 권한
처음 출퇴근 화면에 들어가면 **위치 권한**을 묻습니다. **허용**해야 출퇴근이 가능합니다.

## 4. 현재 버전(v1.0.0)의 제한 사항 — 배포 전 꼭 확인

아래는 실제 코드를 확인한 내용입니다.

1. **로그인은 시험용입니다.** 서버와 연결되어 있지 않아 어떤 이메일/비밀번호를 넣어도 로그인됩니다.
   로그인 후 사용자 정보는 모든 사람이 동일한 예시 값(이름 "김근태", 부서 "개발팀")으로 저장됩니다.
2. **출퇴근 가능 위치가 코드에 고정되어 있습니다.** 위도 37.4979 / 경도 127.0276 (서울 강남역 부근) 반경 100m 안에서만
   출근·퇴근 버튼이 통과합니다. 실제 회사 위치로 쓰려면 앱을 수정해 다시 빌드해야 합니다.
3. **회사 WiFi 이름이 `Company_WiFi`로 고정**되어 있습니다. (WiFi 불일치는 표시만 되고 출퇴근을 막지는 않습니다.)
4. **기록은 휴대폰 안에만 저장됩니다.** 서버(Firebase) 연동은 아직 연결되어 있지 않습니다.
5. **알림 기능은 꺼져 있습니다.** (라이브러리 호환성 문제로 이번 버전에서 제외)
6. 앱 아이콘은 Flutter 기본 아이콘입니다.

## 5. 문제 해결

**Q. "앱이 설치되지 않았습니다"라고 나와요.**
- `arm64` 파일을 받았다면 `SEAON_HR_v1.0.0.apk`(통합 파일)로 다시 받아 설치하세요.
- 이전에 다른 버전이 설치되어 있다면 지우고 다시 설치하세요.

**Q. 출근 버튼을 누르면 "회사 위치(100m)에서만 출퇴근이 가능합니다"가 나와요.**
- 위 4-2 항목 때문입니다. 현재 버전은 고정된 위치에서만 출퇴근이 됩니다.

**Q. "위치 권한이 필요합니다"가 나와요.**
- 휴대폰 설정 → 애플리케이션 → 근태관리 → 권한 → 위치 → **허용**

**Q. 로그아웃하고 싶어요.**
- 오른쪽 위 톱니바퀴(설정) → 맨 아래 **로그아웃**
