## 대표님 요청
- 직원 개인 링크는 **당분간 영구 사용**으로 바꿔 달라.
- 이유: 나중에 이 시스템 전체를 **앱(어플)으로 바꿀 예정**이라, 지금 링크를 1회용으로 두면 불편하다.

## 현재 규칙 (실서버에 적용됨)
- 직원 링크는 **처음 연 기기에서만** 쓸 수 있다 (`emp_enter`가 `link_used_at`을 확인). 2026-10-09 마이그레이션.
- 목적: 링크를 다른 사람이 받아서 대리 출근하는 것을 막기 위해 (대표님 요청 2026-10-10).

## 바꾸면 생기는 일
- 링크가 새어 나가면 누구나 그 직원 이름으로 출퇴근할 수 있다. 대리 출근 방지 효과가 사라진다.
- 새 기기 등록 절차(관리자가 직원 휴대폰에 처음 등록하는 방식, K6)도 필요 없어진다. K6은 이미 보류 중.
- 앱으로 바꾸면 앱 자체 로그인이 생기므로, 그때는 링크 규칙 자체를 다시 설계하는 것이 맞다.

## 제안 (팀장이 결정)
1. **A안 (대표 요청 그대로):** `emp_enter`에서 `link_used_at` 확인을 빼고, 영구 링크로 되돌린다. 새 마이그레이션 파일로 함수만 교체한다(기존 마이그레이션 수정 금지). 화면 변경 없음.
2. **B안 (절충):** 링크는 영구 유지하되, 관리자 화면에 "마지막 접속 기기 수"를 보여 주고 이상하면 "새 링크"로 끊을 수 있게 한다.
3. **C안:** 지금은 현 규칙 유지, 앱 전환 시점에 함께 바꾼다.

## 하이쿠가 하지 않은 것

- L1 마이그레이션(정정·공휴일·백업)은 기존 규칙과 충돌하지 않으므로 별개로 진행 가능하다. 다만 L1은 아직 편집기 문제로 대기 중이다.
