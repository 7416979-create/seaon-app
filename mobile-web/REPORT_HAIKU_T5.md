## 4. 발견한 문제

### 문제 1 (수정 필요): 인수인계서의 테스트 링크 형식이 틀림
- 인수인계서 `make_test_admin_link`는 `'test-' || …` 형식 토큰을 만들라고 되어 있습니다.
- 앱은 주소의 토큰이 **영문 소문자와 숫자만** 되어 있어야 인식합니다. 하이픈이 있으면 `#/login`으로 돌아갑니다.
- 해결: `'tst' || substr(md5(random()::text), 1, 9)` 로 만들어 정상 동작을 확인했습니다.
- 수정 요청: 인수인계서 `make_test_admin_link`, `cleanup_test_data`의 `test-%`를 `tst%`로 바꿔 주세요.

### 문제 2 (확인 필요): 개발 서버에서 400 콘솔 오류
- 관리자 링크 확인 요청(`admin_enter`)이 두 번 나갑니다. 두 번째는 "이미 사용된 링크"로 400이 됩니다.
- 화면은 정상입니다. 앱이 이미 로그인된 상태이면 그대로 넘어갑니다.
- 원인은 개발 모드(React StrictMode)의 중복 실행으로 보입니다. 배포 빌드에서도 같은지는 **T8에서 확인 필요**합니다.

### 문제 3 (수정 필요): 신청 화면 문구가 오래됨
- 휴가 신청 화면 하단에 "관리자 기능은 서버 연동 후 제공됩니다"라는 문구가 그대로 있습니다.
- 지금은 서버가 연결되어 있으므로 이 문구를 지워야 합니다. (코드 위치: 신청 화면 파일 `src/pages/Leave.tsx`에서 해당 문구 검색)

### 문제 4 (확인됨, 문제 아님): 403 한 건
- 확인하려고 `.env` 파일을 직접 열었는데 Vite가 막았습니다. 키가 노출되지 않는 정상 동작입니다.

## 5. 팀장 판단이 필요한 것

1. **테스트 데이터를 실제 배포 DB에 두고 있습니다.** 배포 전에 삭제할지, 배포 전에 별도 테스트 프로젝트를 만들지 결정해 주세요.
2. **회사 위치(본사)가 테스트 값으로 저장되어 있습니다.** 지금 상태에서 직원이 출근하면 반경 150m 제한이 걸리기 시작합니다. 아직 `geofence`(회사 근처에서만 출퇴근) 옵션은 꺼져 있어 출퇴근이 막히지는 않습니다.
3. **관리자 세션 기록이 남아 있습니다.** 실제 관리자가 쓸 때 영향은 없지만, 삭제 SQL에서 `admin_sessions`를 전부 지우므로 실제 관리자 로그인 상태도 끊깁니다. 실제 관리자는 아직 접속한 적이 없으니 영향 없음을 확인했습니다.
