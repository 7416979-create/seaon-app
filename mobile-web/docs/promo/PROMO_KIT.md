## 1. 한 줄 소개 (택1)
- 누구나 쉽게 쓰는 출퇴근 앱, 세아온 근태관리
- 글씨는 크게, 출근은 한 번에
- 장애인 고용 사업장을 위해 만든 쉬운 근태관리

## 2. 핵심 장점 3가지 (지금 실제로 되는 것만)
1. **큰 글씨 보기** — 버튼 하나로 글자와 버튼이 커집니다.
2. **링크 하나로 시작** — 아이디·비밀번호 없이 받은 링크를 열면 바로 씁니다. 처음 연 휴대폰에서만 쓸 수 있어 대리 출근을 막습니다.
3. **실수해도 고칠 수 있음** — 퇴근을 깜빡해도 정정 신청을 하면 관리자가 승인합니다.

보조 문구: 회사 위치 확인 출퇴근 · 휴가 신청과 승인 · 월별 근태 요약 내려받기 · 휴대폰 홈 화면에 앱처럼 설치

## 3. 대상별 문구
- **사업주:** "직원이 헷갈리지 않는 근태관리. 관리자는 한 화면에서 승인하고, 월별 요약을 내려받습니다."
- **직원:** "출근 버튼 하나. 글씨가 작으면 크게 바꾸세요."
