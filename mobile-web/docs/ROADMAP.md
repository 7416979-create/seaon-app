# 세아온 근태관리 로드맵

작성: 2026-10-10 (Claude Haiku 5.5, 팀장 지시 K9). 대표 의견을 정리한 문서이며, 아직 구현하지 않은 항목은 "예정"입니다. 법률 판단이 필요한 항목은 전문가 검토를 거쳐야 합니다.

## 1단계: 근태 기본 (진행 중)
| 항목 | 상태 |
|---|---|
| 서버 연결 (Supabase), 직원·관리자 화면 | ✅ |
| 출퇴근, 휴가 신청·승인, 회사 위치 제한, 근무 시간 설정 | ✅ |
| 여러 명 등록, 전체 링크 복사 | ✅ |
| 처음 기기만 개인 링크 사용 (대리 출근 방지) | ✅ 서버 적용, 실서버 마이그레이션 2는 대기 |
| 직원 휴대폰 번호, 기기 등록 상태 표시 | 🔄 화면 코드 완료, DB 적용 대기 |
| 휴대폰 등록 방법 안내 (관리자가 직원 휴대폰에 등록) | ⏸ 대표 결정 대기 |

## 2단계: 근로계약서·사직서
- 계약서 양식 등록, 수정 부분 빨간색 표시
- 수정 고지 문구: "수정에 따른 책임은 (가입회사명)에 있습니다."
- 동의 체크(★)와 동의 시각 저장
- 사직서 항목 추가, 전자서명
- 필요: 파일 저장소(Supabase Storage), 노무사·법률 검토 (전자서명 효력, 동의 문구)
- AI 검증은 검증 기준과 책임 범위를 정한 뒤 결정 (외부 AI 비용 별도)

## 3단계: 알림톡·문자
- 발송 업체 선정, 발신번호 등록
- 건당 과금 (금액은 업체 공식 요금 확인)
- 수신자 동의 확인

## 4단계: 인재풀·구인 매칭 (별도 프로젝트)
대표 의견: "모두의 잡"처럼 인재를 검색하고 구인 회사에 추천하는 사이트.
- 구인 등록 순서별 추천, 취업 연락 회신 시 후순위
- 플랜별 검색 결과 노출 인원
- 기존 근로자 등록: 기존 근로계약서 첨부, 1개월 이상 근로자만 등록
- 근로계약서 등록 후 확인 뒤 등재
- 풀 검색 시 개인정보 별표 처리, 알림톡·문자 발송 설정

**착수 전 법률 검토 필수**
- 개인정보 보호법: 동의, 최소 수집, 마스킹
- 채용절차법: 채용 과정의 정보 수집·공개 제한
- 직업안정법: 구인·구직을 유료로 연결하면 직업소개사업 신고·등록 대상일 수 있음

## 공통 원칙
- 주민등록번호는 수집하지 않습니다.
- 개인정보는 화면에서도 필요한 만큼만 보여 주고, 나머지는 가립니다.
- 브라우저는 휴대폰 번호를 자동으로 읽을 수 없으므로, 번호는 등록 때 입력합니다.

## 비용 메모 (확인 필요)
- Supabase: 무료 구간을 넘으면 유료 요금제 (금액은 공식 요금표 확인)
- 문자·알림톡: 건당 과금
- 법률 검토, 보안 점검 비용은 별도
