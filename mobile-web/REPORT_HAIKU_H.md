## 확인 메모
- H2 병합 전에 작업 폴더에 커밋되지 않은 문서 3개가 있어서 체크아웃이 막혔습니다. 전체 관리자 링크가 들어 있지 않은 것을 확인하고, `supabase-backend`에 먼저 커밋(`08573959`)한 뒤 병합했습니다.
- 인수인계서 H4 검사 명령 안에 전체 관리자 링크가 한 번 적혀 있었습니다. 가려서(`b7sh…(가림)`) 제거했습니다.
- H1 좌표는 카카오맵에서 건물 정확 좌표를 읽지 못해서 **거리(선유로13길) 단위 좌표**를 썼습니다. 건물과 수십 m 어긋날 수 있습니다. 대표님이 관리자 화면 → 설정 → 회사 위치에서 지도의 건물을 클릭해 다시 저장하면 정확해집니다.
- 사이트 확인에 쓴 탭 1개(Supabase SQL 편집기)는 편집 내용이 저장되지 않은 상태로 남아 있습니다. 실행은 새 탭에서 했습니다.

## 대표님 할 일 (순서대로)
1. 테스트할 사람이 오면 관리자 링크(노션 "관리자 접속 정보" 페이지에 있음)를 관리자 PC에서 한 번 열기
2. 설정 → 비상 로그인 비밀번호 정하기 → 노션에 적기
3. 설정 → 회사 위치: 지도에서 건물 클릭 후 저장 (정확도 개선)
4. 직원 등록 → 개인 링크로 출퇴근 한 번 시험

## 남은 항목 (팀장 판단)
- 개발 서버에서 보인 관리자 링크 중복 호출(400)은 배포 빌드에서 확인하지 않았습니다.
- 관리자가 여러 명이어도 '관리자' 한 명으로 표시됩니다 (다음 단계 과제).
