## 6. 대표님 의견 (기능 요청, 오퍼스 검토용 · 아직 구현 안 함)

대표님 의견을 항목별로 정리했습니다. 각 항목에 구현 가능성과 법적 확인이 필요한 부분을 함께 적었습니다. 법률 판단은 제가 하지 않으니 전문가 확인이 필요합니다.

### 6-1. 근로계약서 관련
- **수정사항 빨간색 표시 + 책임 고지:** 구현 가능. 수정된 부분을 빨간색으로 표시하고, "수정에 따른 책임은 가입회사명에 있습니다" 문구를 넣는 방식.
- **동의서 회수 후 ★동의 체크:** 구현 가능. 수정 계약서에 대한 동의 체크를 받아 저장.
- **AI 검증을 거친 계약서만 등록 가능:** 구현 가능하지만 **AI 검증의 기준과 책임 범위를 먼저 정해야 함.** 외부 AI 서비스 비용이 추가됨.
- **사직서 항목 추가 + 서명 가능:** 구현 가능. 전자서명은 서명 방식(직접 그리기, 이미지 업로드 등)에 따라 법적 효력 검토가 필요함.

### 6-2. 관리자 페이지 (인재 풀)
- **풀 검색 시 개인정보 별표 처리 (주민번호, 주소, 이름 등):** 구현 가능. 다만 **주민등록번호는 수집 자체가 제한된 항목**이라(개인정보 보호법), 애초에 수집하지 않는 방향을 권장.
- **알림톡·SMS 발송 설정:** 구현 가능. 단, 발신번호 등록과 건당 요금 발생, 수신자 동의 확인 필요.
- **구인 회사에 인재 풀 추천 (구인 등록 순서별, 취업 연락 오면 후순위):** 구현 가능. 순서 규칙을 정확히 정해야 함.
- **인재 검색 결과 노출 수는 플랜에 따라 제한:** 구현 가능. 플랜 정보(요금제 구조)를 먼저 정해야 함.
- **기존 직원 등록 시 기존 근로계약서 첨부, 한 달 이상 근로자만 등록:** 구현 가능. 첨부 파일 저장소와 "한 달 이상" 기준을 확인하는 칸이 필요함.
- **근로계약서 등록 후 확인 뒤 등재:** 구현 가능 (승인 단계 추가).

### 6-3. 출퇴근 관련
- **실제 출퇴근 사용자의 핸드폰 번호 자동 입력:** **웹 브라우저로는 휴대폰 번호를 자동으로 읽을 수 없습니다.** 직원 등록 때 번호를 한 번 입력받아 저장하는 방식만 가능합니다.

### 6-4. 플랫폼화 (모두의 잡 같은 인재 검색 사이트)
- **기능적으로는 가능**하지만, 지금 구조(직원 근태 관리)와는 **별도의 서비스 규모**입니다.
- **비용 대략 (확인 필요):**
  - 서버(Supabase): 무료 구간을 넘으면 월 25달러 수준부터 시작 (요금은 바뀔 수 있음)

  - 개인정보 처리 시스템 구축, 보안 점검, 법률 검토 비용
- **가장 큰 위험:** 인재 정보를 대량으로 모으고 노출하면 **개인정보보호법과 채용 절차법의 적용**을 받습니다. 개발 전에 법률 검토가 먼저 필요합니다.

### 6-5. 정리 권고
1. 지금 서버 작업(처음 기기만 링크)과 별개로, 위 기능들은 **개발 순서를 먼저 정한 뒤** 진행하는 것을 권합니다.
