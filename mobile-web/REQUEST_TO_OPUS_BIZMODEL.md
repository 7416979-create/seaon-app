# 요청: 사업 구조 메모 정리 (대표님 제안, Haiku → Opus)

- 작성: Claude Haiku 5.5 (개발팀원), 2026-10-11
- 대상: Claude Opus 5.5 (팀장)
- 성격: 설계 의견 요청. 코드 작업 아님. 회신 전에는 아무것도 바꾸지 않습니다.

## 대표님 제안 (원문 요지)
1. **사이트 운영은 "모두의잡"처럼 한다.** 구인·구직 연결 사이트를 운영한다.
2. **관리용 앱은 따로 판매한다.** 근태 관리 앱을 별도 상품으로 판다.
3. **모두의잡에서 채용한 회사에는 앱 할인.** 사이트를 통해 사람을 뽑은 회사는 앱 구매 시 할인을 준다.

## 샤플 운영 구조 (공개 자료로 확인한 범위)
조사 결과, 샤플은 **구직 사이트가 아니라 근태·인사 관리 SaaS**입니다. 대표님이 말씀하신 "구직 연결 + 앱 할인" 구조를 샤플에서 찾지는 못했습니다.

## 팀장께 확인 요청
1. **모두의잡 방식(사이트 운영 + 앱 판매 + 채용 회사 할인)의 법률·수익 구조 검토.** 특히 구인·구직을 유료로 연결하면 직업안정법상 직업소개사업 신고 대상일 수 있습니다(ROADMAP.md 4단계와 같은 문제). 샤플 참고와 별개로 전문가 검토가 필요합니다.
2. **"채용하면 할인" 조건의 측정 방법.** 사이트에서 채용이 실제로 이루어졌는지 어떻게 확인할지(근로계약서 업로드, 확인 절차 등). 개인정보 최소 수집 원칙과 충돌하지 않게 설계해야 합니다.
3. **관리용 앱 판매 시점.** 지금 웹(PWA)에서 검증 중인 근태 기능을 먼저 쓰게 한 뒤 앱으로 파는 순서가 맞는지, 아니면 앱 전환(샤플 참고)을 먼저 할지.
4. 현재 코드베이스에는 구직 매칭 기능이 없습니다(법률 확인 전 보류 상태). 이 요청은 설계 의견만 받는 것이고, 구현은 회신 뒤 별도 지시로 진행합니다.

## 대표님께 전달할 확인 사항

- "모두의잡 방식"의 실제 운영 주체(사이트 운영 회사, 앱 판매 회사)를 나눌지 정해 주세요.

## 추가 요청: 샤플 대비 접근 방식과 홍보 방법

- 작성: Claude Haiku 5.5 (개발팀원), 2026-10-09
- 성격: 설계 의견 요청. 코드, Supabase, 라이브 사이트는 건드리지 않았습니다.

### A. 샤플과 비교한 우리의 접근 방식

| 구분 | 샤플 | 세아온 근태관리 (우리) |
|---|---|---|
| 주 대상 | 기업 규모 전반의 인사·근태 SaaS. 베어베터 등 장애인 고용 사업장도 고객 | 장애인 고용 사업장, 소규모 사업장 |
| 출결 인증 | GPS, QR, 안면 인증 ([근태 기능 안내](https://www.shoplworks.com/help-center/help-center-admin/shopl-attendance-management)) | 링크 기반 기기 등록 + 회사 반경 검증 |
| 화면 | 기능 중심. 베어베터 도입 사례에서 쉬운 화면이 강조됨 ([사례](https://www.shoplworks.com/blog-usecases/bearbetter-disability-workforce-attendance)) | 장애인 친화 UI, 큰 글씨 |
| 기능 폭 | 근태, 휴가, 전자문서, 채팅 등 넓음 | 근태 중심. 휴가·전자문서 등은 부족 |

**차별화 주의:** 샤플도 "쉬운 화면"을 장애인 고용 사례로 내세우고 있습니다. 따라서 "장애인 친화 UI"만으로는 차별점이 약합니다. 소규모 사업장에 맞는 가격, 안면 인증 없이 쓰는 기기 등록 방식, 현장 운영 편의처럼 구체적인 이유를 같이 내세워야 합니다.

**요금 아이디어 (금액은 모두 미정, 미확인):**
- 사업장당 월 정액 앱 요금 vs 인원당 과금. 소규모 사업장에는 정액이 부담이 적을 수 있으나, 실제 반응은 검증이 필요합니다.
- 일정 인원 이하 무료. 가입과 기기 등록을 늘리기 위한 진입 장치입니다.
- 샤플 요금 (2026-10-09 확인, [공식 요금 페이지](https://www.shoplworks.com/pricing)): **사용자(인원) 1명당 월 요금**, VAT 별도. Lite 1,800원(표시 2,000원에서 10% 할인), Standard 3,600원(4,000원에서 할인), Pro 6,300원(7,000원에서 할인), Enterprise는 별도 문의. 두 가격 중 낮은 쪽이 연간 결제로 보이나 페이지에 명시되지는 않음. 우리 설계에 주는 의미: 샤플은 인원당 과금이므로 사업장당 정액이면 인원이 많은 고객에게 유리합니다. 이 숫자를 기준으로 가격을 비교하세요. 샤플 이용료 지원 조건은 여전히 미확인입니다.
- 대표님 제안(사이트를 통해 채용한 회사에 앱 할인): 할인율, 기간, 채용 사실 확인 방법 모두 미정입니다. 채용 여부를 확인하려면 근로계약서 등 민감한 자료가 필요해질 수 있어 B, C 항목과 함께 봐야 합니다.

**위험 요소:**
- **직업안정법:** 구인·구직을 연결하고 수수료를 받으면 직업소개사업에 해당할 수 있습니다. 검색 자료에서는 신고가 아니라 **등록** 대상으로 설명합니다. 이 자료는 2차 블로그라 원문 확인이 필요합니다. 무등록 유료 직업소개의 처벌 수위는 [참고 자료](https://www.help-me.kr/blog/article/%EC%A7%81%EC%97%85%EC%86%8C%EA%B0%9C%EC%82%AC%EC%97%85%EB%B2%95%EC%9D%B8%EC%84%A4%EB%A6%BD/)에 5년 이하 징역 또는 5천만 원 이하 벌금으로 나오지만 미확인입니다. 앞선 요청서의 "신고"도 "등록"으로 정정이 필요할 수 있습니다.
- **개인정보:** 채용 확인을 위해 근로계약서를 받으면 최소 수집 원칙과 충돌할 수 있습니다. 법률 검토 전에는 수집하지 않는 방향이 안전합니다.
- **기능 부족:** 샤플 대비 휴가, 전자문서 등이 없어 영업 시 약점이 됩니다.
- **고객 자격:** 장애인표준사업장 지원은 장애인 근로자 10명 이상 등 조건이 있습니다([제도 설명, 2차 자료](https://www.guard1004.com/m/360)). 소규모 고객 중 이 조건에 못 미치는 곳이 많을 수 있습니다. 최신 기준은 미확인입니다.

### B. 홍보 방법 (저비용 채널)

**사업주 대상**
1. **한국장애인고용공단 지역본부·지사:** 사업주 상담 창구입니다. 공식 사이트는 kead.or.kr로 검색 자료에 언급되었으나 직접 열어 확인하지 못했습니다. 지사 방문 상담과 안내 자료 비치를 요청할 수 있습니다.
2. **장애인표준사업장·사회적기업 네트워크:** 인증 기업 목록과 협회 게시판을 통해 소개를 받을 수 있습니다. 기업 수와 연락처 확보 방법은 미확인입니다.
3. **지자체 장애인 일자리 사업:** 시·군·구청 고용 담당 부서에 문의해 사업 공고와 연계 여부를 확인합니다. 구체적 사업명은 미확인입니다.
4. **도입 사례 콘텐츠:** 실제 사용 기업의 짧은 후기 글과 영상을 블로그와 유튜브에 올립니다. 샤플 사례와 겹치지 않도록 소규모 사업장 사례를 우선합니다.
5. **온라인 커뮤니티:** 사회적기업, 장애인 고용 관련 카페와 단체 게시판에 사례 중심 글로 소개합니다. 광고성 게시는 커뮤니티 규칙을 먼저 확인합니다.
6. **제휴:** 노무사, 세무사, 사회복지 관련 기관과 추천 제휴를 맺는 방법을 검토합니다. 추천 수수료 구조는 법률 검토가 먼저입니다.

**구직자 대상**
- 지역 장애인복지관과 취업 지원 프로그램, 공공 구인 채널(예: 워크넷) 연계를 검토합니다. 구체적 연계 방식은 미확인입니다.

**효과 측정**
- 채널별 방문 수, 사업장 가입 수, 기기 등록 완료 수, 무료에서 유료로 넘어간 비율을 월 단위로 기록합니다.
- 채널마다 다른 출처 태그를 링크에 붙입니다. 예: `?src=kead`. 개인정보는 URL에 넣지 않습니다.
- 채널당 비용을 같이 기록해 가입 1건당 비용을 비교합니다. 목표 수치는 대표님과 정한 뒤 적습니다.

### C. 확인 필요 사항 (대표님)
1. 샤플 실제 요금과 할인 제도는 영업 문의 또는 공식 요금 페이지에서 직접 확인이 필요합니다.
2. 모두의잡 방식(구인·구직 연결 + 수수료 또는 할인 연계)이 직업안정법상 등록 대상인지 노무사 또는 변호사 검토가 필요합니다. 앞선 요청서의 "신고"는 "등록"일 수 있습니다.
3. "채용하면 할인"의 채용 확인 방법. 개인정보 최소 수집 원칙과 함께 정해 주세요.

5. 우선 타깃: 장애인표준사업장 vs 일반 소규모 사업장.
6. 홍보 예산과 담당자, 첫 달에 목표로 할 가입 수를 정해 주세요.
