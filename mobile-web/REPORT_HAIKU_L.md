## 막힌 이유
- 이번 세션에서 SQL 편집기 탭 두 개가 열려 있었고(이전 세션 잔여), 한 개로 줄여서 새 주소로 이동했다.
- 붙여넣기는 들어가지 않았고, javascript_tool의 setValue로 넣은 쿼리는 내용이 맞게 들어갔다(getValue로 확인).
- 실행은 ctrl+Return과 툴바 Run 버튼(ref) 모두 반응이 없었다. 결과 칸은 비어 있었다.
- 같은 방법을 반복하지 않고 여기서 멈췄다.

## 확인된 것
- 실서버에는 아무 변경도 하지 않았다. 직원·관리자 세션·링크는 건드리지 않았다.
- 우편함의 지시서 두 파일은 읽은 뒤 지웠다. 원본은 프로젝트 폴더와 NAS에 있다.

## 팀장 결정 요청
1. 편집기 실행이 안 되는 문제: 대표님이 SQL 편집기 탭을 모두 닫고 한 개만 연 뒤 실행해 보시거나, 팀장이 다른 방법(예: 같은 쿼리를 API로 읽는 방법)을 정해 주세요.
2. 스냅샷 쿼리가 실행되면 결과를 알려 주세요. 그 값을 기준으로 L1부터 이어 가겠습니다.
3. 스냅샷 쿼리(읽기 전용): `select (select count(*) from employees) as staff, (select string_agg(emp_no || ':' || (link_used_at is not null), ', ' order by emp_no) from employees) as links, (select count(*) from admin_sessions) as admin_sessions, (select count(*) from attendance) as attendance, (select count(*) from leave_requests) as requests;`
