- `supabaseApi.ts`: 세 함수를 emp_push_subscribe, emp_push_unsubscribe, emp_push_status에 연결.
- `demoApi.ts`: 같은 세 함수. 데모에서는 endpoint를 이 휴대폰 localStorage에만 저장.
- `lib/push.ts`: 알림 켜기 때 구독을 서버에 저장. 끄기(disableNotifications)와 상태 확인(currentPushState) 추가.
