# 회신: 사업 구조 (Opus → 대표님·Haiku)

- 작성: Claude Opus 5.5 (팀장), 2026-10-11
- 대상 요청서: REQUEST_TO_OPUS_BIZMODEL.md
- 성격: 설계 의견. 법률 자문이 아닙니다. 최종 판단은 노무사·변호사 검토 후에 합니다.

## 1. 대표님 결정에 대한 의견
- **사이트 무료, 앱만 유료, 채용 연계 할인 없음: 찬성.** 채용 성사와 돈을 떼어 놓으면 "유료 직업소개" 위험이 크게 줄어듭니다.

## 2. 새로 확인한 중요한 점: "무료"라도 아무나 할 수 있는 것은 아닐 수 있음
직업안정법 조문을 찾아봤습니다. **아래는 2009년 시행판(법률 제9432호) 기준이라 현재 법과 다를 수 있습니다.** ([위키문헌 직업안정법](https://ko.wikisource.org/wiki/%EC%A7%81%EC%97%85%EC%95%88%EC%A0%95%EB%B2%95))

| 구분 | 내용 (2009년판) |
|---|---|
| 직업소개의 뜻 (제4조) | 구인·구직 신청을 받아 **고용계약 성립을 알선**하는 것 |
| 무료직업소개 (제18조) | 시·군·구청장에게 **신고**. 그리고 **비영리법인 또는 공익단체로 한정** |
| 유료직업소개 (제19조) | 시·군·구청장에게 **등록** |
| 벌칙 | 신고 없이 무료 소개: 1년 이하 징역 또는 500만 원 이하 벌금. 등록 없이 유료 소개: 5년 이하 징역 또는 2천만 원 이하 벌금 |

**의미:** 세아온이 영리 회사라면, 돈을 받지 않더라도 "무료직업소개"를 직접 하기 어려울 수 있습니다(2009년판 제18조 제2항). 현재도 이 제한이 있는지가 노무사에게 물어볼 첫 질문입니다.

## 3. 팀장 제안: "소개(알선)"가 아니라 "정보 게시판"으로 설계
- 같은 법에는 **직업정보제공사업**(구인·구직 정보를 게시하는 사업, 2009년판 제23조, 신고 대상)이 따로 있습니다.
- 사이트를 **회사가 공고를 올리고 구직자가 직접 지원하는 게시판**으로 만들면, 우리가 중간에서 "이 사람을 이 회사에 추천"하는 알선보다 법적 부담이 작을 가능성이 큽니다.
- 그래서 **"인재 추천", "매칭", "우리가 연결해 드림" 기능과 표현은 법률 확인 전까지 만들지 않습니다.**
- 이 방향도 신고가 필요한지, 영리 회사가 할 수 있는지 노무사 확인이 필요합니다.

## 4. 노무사·변호사에게 물어볼 질문 (그대로 보여 주시면 됩니다)
1. 영리 법인이 구인·구직 정보를 무료로 게시하는 사이트를 운영하면 직업정보제공사업 신고 대상인가?
2. 같은 회사가 근태관리 앱을 유료로 팔 때, 사이트와 앱을 한 회사에서 해도 되는가?
3. 공고 게시만 하고 추천·알선은 하지 않으면 직업소개사업에 해당하지 않는가?
4. 현재 직업안정법에서 무료직업소개사업이 비영리법인·공익단체로 한정되는가?
5. 장애인 구직자 정보(장애 유형 등)를 받을 때 필요한 동의와 보관 기준은?

## 5. 샤플 대비 접근 (Haiku 정리에 대한 의견)
- Haiku 정리 방향은 맞습니다. 덧붙일 점:
  - **가격 비교 기준이 생겼습니다.** 샤플은 1인당 월 1,800~6,300원(VAT 별도, 2026-10-09 공식 요금 페이지)입니다. 우리는 "직원 10명 이하 사업장 무료" 또는 "사업장당 정액"처럼 소규모 장애인 고용 사업장이 계산하기 쉬운 가격이 차별점이 될 수 있습니다. 금액은 대표님이 정하실 일입니다.
  - **"장애인 친화"는 말이 아니라 보여 줘야 합니다.** 샤플도 쉬운 화면을 장애인 고용 사례로 내세웁니다. 큰 글씨, 화면 낭독기 지원, 링크 한 번으로 시작하는 방식(아이디·비밀번호 없음)을 실제 화면으로 보여 주는 게 낫습니다.
  - **기능 차이는 인정하고 범위를 좁힙니다.** 샤플처럼 다 하려 하지 말고, 출퇴근·휴가·정정·월 요약을 가장 쉽게 하는 앱으로 갑니다. 근로계약서·사직서(로드맵 2단계)는 그다음입니다.

## 6. 홍보 (팀장 의견)
1. **첫 사례는 세아온 자체.** 지금 실제로 쓰고 있는 직원 경험(큰 글씨, 정정 신청 등)을 짧은 사례 글로 만듭니다. 대표님 확인 후 공개합니다.
2. **장애인 고용 사업장 대상 무료 체험.** 표준사업장·사회적기업 몇 곳에 1~2개월 무료로 써 보게 하고 의견을 받습니다.
3. **공공 채널은 문의부터.** 한국장애인고용공단 지사, 지자체 장애인 일자리 담당에 "소개 자료를 비치해도 되는지" 먼저 묻습니다. 공공기관이 특정 상품을 홍보해 주지는 않을 수 있습니다.
4. **측정:** 채널별 링크 태그(예: `?src=kead`, 개인정보는 넣지 않음)로 가입 수와 실제 사용 수를 셉니다. 이건 개발로 지원할 수 있으니, 원하시면 다음 차수에 넣겠습니다.
