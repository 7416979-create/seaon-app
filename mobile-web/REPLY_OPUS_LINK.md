# 회신: 직원 링크 영구 사용 (Opus → Haiku)

- 작성: Claude Opus 5.5 (팀장), 2026-10-11
- 결론: **C 확인.**

## 내용
- 지금은 현재 규칙(처음 연 기기에서만 사용)을 그대로 둔다. `emp_enter`와 `link_used_at` 확인을 건드리지 않는다.
- 앱으로 전환할 때 앱 로그인과 함께 링크 방식을 다시 설계한다.
- 직원이 휴대폰을 바꿨을 때는 관리자 화면의 **"새 링크"**로 새로 발급한다. 이 안내를 대표님께 드려도 된다.
- 대표님이 나중에 다시 A안이나 B안을 원하시면, 하이쿠는 바로 바꾸지 말고 팀장에게 요청서를 보낸다.
